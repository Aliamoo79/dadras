# دادرس — دموی سامانه هوش مصنوعی قضایی

یک Proof of Concept فارسی و راست‌به‌چپ برای نمایش گردش کامل تحلیل پرونده؛ از دریافت سند تا رأی پیشنهادی و صحت‌سنجی استنادات.

> این پروژه صرفاً نمایشی و آموزشی است. داده‌ها، قوانین و خروجی‌ها ساختگی‌اند و هیچ‌کدام اعتبار قضایی ندارند.

## اجرا

```bash
npm install
npm run dev
```

برای تولید نسخه نهایی:

```bash
npm run build
npm run preview
```

## آنچه در دمو می‌بینید

- رابط فارسی RTL و واکنش‌گرا برای قاضی یا مدیر دادگستری
- دو پرونده ساختگی و ورودی نمایشی PDF/صوت
- اجرای زنده یک state machine شامل ده عامل در پنج لایه
- گزارش مستقل هر عامل، دلیل تصمیم و شواهد مورد استفاده
- پیش‌نویس رأی با نقطه تصمیم صریح برای قاضی انسانی
- فهرست مواد قانونی نمونه و نتیجه اعتبارسنجی
- رعایت فوکوس صفحه‌کلید و تنظیم `prefers-reduced-motion`

## انتخاب فنی

دمو با React، TypeScript و Vite ساخته شده است. هماهنگ‌کننده چندعاملی فعلاً یک state machine قطعی در مرورگر است تا اجرای ارائه بدون کلید API، شبکه یا داده قضایی واقعی ممکن باشد. داده‌ها و قراردادهای عامل‌ها در `src/data.ts` جدا شده‌اند؛ بنابراین می‌توان اجرای mock را بعداً با API مبتنی بر FastAPI/LangGraph، سرویس OCR/ASR و Vector DB جایگزین کرد.
