# دادرس — دموی سامانه هوش مصنوعی قضایی

یک Proof of Concept فارسی و راست‌به‌چپ برای نمایش گردش کامل تحلیل پرونده؛ از دریافت سند تا رأی پیشنهادی و صحت‌سنجی استنادات. هر مرحله اکنون می‌تواند واقعاً از یک مدل محلی Ollama یا API سازگار با OpenAI پاسخ بگیرد.

> این پروژه صرفاً نمایشی و آموزشی است. داده‌ها، قوانین و خروجی‌ها ساختگی‌اند و هیچ‌کدام اعتبار قضایی ندارند.

## اجرا

```bash
npm install
npm run dev
```

در ویندوز PowerShell از `npm.cmd` استفاده کنید:

```powershell
npm.cmd install
npm.cmd run dev
```

سپس `http://localhost:5173` را باز کنید. فرمان توسعه، رابط Vite و درگاه امن مدل روی پورت `8787` را هم‌زمان اجرا می‌کند.

## اجرای مدل محلی Gemma با Ollama

1. Ollama را نصب و اجرا کنید.
2. یک مدل Gemma موجود را دریافت کنید؛ برای نمونه:

```powershell
ollama pull gemma3:4b
```

3. برنامه را باز کنید و از بالای صفحه وارد «تنظیمات مدل زبانی» شوید.
4. «مدل محلی» را انتخاب و این مقادیر را وارد کنید:

```text
نشانی سرویس: http://127.0.0.1:11434
نام مدل: gemma3:4b
```

5. «آزمایش اتصال» را بزنید. اگر مدل دیگری با نامی مانند `gemma4` روی Ollama نصب کرده‌اید، همان نام دقیق خروجی `ollama list` را وارد کنید.

## استفاده از API

در تنظیمات «API سازگار» را انتخاب کنید و Base URL، شناسه مدل و کلید API را وارد کنید. برای OpenAI، Base URL برابر `https://api.openai.com/v1` است. کلید فقط در حافظه فعال صفحه نگه داشته می‌شود و در localStorage نوشته نمی‌شود.

درخواست‌ها از مرورگر به سرور محلی Dadras می‌روند و سرور آن‌ها را به ارائه‌دهنده مدل ارسال می‌کند. این معماری از تماس مستقیم رابط با ارائه‌دهنده جلوگیری می‌کند، اما برای استقرار واقعی بهتر است کلید API فقط در environment سرور نگهداری شود.

برای تولید نسخه نهایی:

```bash
npm run build
npm run preview
```

## آنچه در دمو می‌بینید

- رابط فارسی RTL و واکنش‌گرا برای قاضی یا مدیر دادگستری
- دو پرونده ساختگی و ورودی نمایشی PDF/صوت
- اجرای ترتیبی ده درخواست واقعی به مدل در پنج لایه
- ارسال خروجی عامل‌های قبلی به عامل بعدی به‌عنوان زمینه استدلال
- گزارش مستقل هر عامل، مدل پاسخ‌دهنده و زمان پاسخ
- توقف خودکار روی خطا و امکان اصلاح تنظیمات و تلاش دوباره
- پیش‌نویس رأی با نقطه تصمیم صریح برای قاضی انسانی
- فهرست مواد قانونی نمونه و نتیجه اعتبارسنجی
- رعایت فوکوس صفحه‌کلید و تنظیم `prefers-reduced-motion`

## انتخاب فنی

دمو با React، TypeScript، Vite و یک gateway کوچک Express ساخته شده است. هماهنگ‌کننده در مرورگر هر عامل را به ترتیب اجرا می‌کند و `server/index.mjs` درخواست را به Ollama یا endpoint سازگار با OpenAI می‌فرستد. داده‌ها و وظیفه تخصصی هر عامل در `src/data.ts` تعریف شده‌اند. OCR/ASR، RAG واقعی و Vector DB هنوز مرحله بعدی توسعه هستند؛ متن پرونده فعلاً از داده نمونه برنامه می‌آید.
